FOREVER ADDONS

Launch Forever Addons from the application menu or desktop shortcut.
Alternatively, run python3 app.py from the application directory.

CurseForge: Browse CurseForge -> Set API key -> Search.
You need your own CurseForge API key, not your account password.
Enter the key directly in the application, never in chat or the repository.
The key settings dialog links to instructions for requesting API access.

Search by addon name, author, or project ID. An empty query lists popular
addons for your Forever client version. Sort and paginate the results.
Install verifies the stable release, download, and ZIP contents.
Installed packages also support Update all. Required dependencies must be
installed separately; their names and IDs are reported. Some authors disable
third-party distribution; use the addon website and import a ZIP instead.

GitHub: enter owner/repository. Use Import ZIP for local packages.
Update manually imported ZIPs by importing a newer ZIP.
Exit WoW before making changes and do not start it during installation.
Backups: ~/.local/share/forever-addons/backups.
File verification compares files with their installation manifest; it is not
a malware scan. Restore latest backup replaces affected addon files with
their state before the latest operation. WTF character settings are preserved.

See README.md in this directory for complete setup instructions, account
switching, limitations, troubleshooting, and command-line usage.
